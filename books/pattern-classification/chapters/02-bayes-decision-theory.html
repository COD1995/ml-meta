Chapter 2: Bayesian Decision Theory

2.1 Introduction

Bayesian decision theory is a foundational approach to pattern classification that uses probability to quantify the tradeoffs between different decisions. It provides a formal framework for making optimal decisions when there's uncertainty. The core assumption is that we can describe the problem using probabilities.

Let's use a classic example: classifying fish. 🐟 Imagine you're designing a machine to separate sea bass from salmon on a conveyor belt. The true identity of the next fish is uncertain. We call this true identity the state of nature, denoted by $\omega$. Let $\omega = \omega_1$ for sea bass and $\omega = \omega_2$ for salmon.

Before we even see the fish, we might have some prior knowledge. For instance, we might know that the current catch is 70% sea bass and 30% salmon. This is called the prior probability, $P(\omega_j)$. Here, $P(\omega_1) = 0.7$ and $P(\omega_2) = 0.3$. If we had to make a decision without any other information, our best bet is to always guess the most likely class (sea bass). This simple rule would be correct 70% of the time. The probability of error is simply the smaller prior, $P(\omega_2) = 0.3$.

To do better, we need more information. Let's say we measure a feature, like the lightness of the fish's skin, which we'll call $x$. We expect that the distribution of lightness values for sea bass is different from that for salmon. This is captured by the class-conditional probability density function, $p(x|\omega_j)$. This function tells us the probability of observing a certain lightness value $x$ *given* that the fish belongs to class $\omega_j$.

Now, we have two key pieces of information: the priors $P(\omega_j)$ and the class-conditional densities $p(x|\omega_j)$. How do we combine them? This is where Bayes' formula comes in:

$$ P(\omega_j | x) = \frac{p(x | \omega_j) P(\omega_j)}{p(x)} $$

This formula is incredibly powerful. It lets us update our initial belief (the prior) with new information (the evidence) to get a more informed belief (the posterior). Let's break it down:

  • Posterior Probability ($P(\omega_j|x)$): The probability of class $\omega_j$ *after* observing the feature $x$. This is what we want to calculate.
  • Likelihood ($p(x|\omega_j)$): How likely is the feature value $x$ for a fish from class $\omega_j$? It tells us how well the class "explains" the data.
  • Prior Probability ($P(\omega_j)$): Our belief about the probability of class $\omega_j$ *before* seeing any data.
  • Evidence ($p(x)$): The overall probability of observing feature $x$, regardless of class. It acts as a normalization constant to ensure the posterior probabilities sum to 1. For classification, we can often ignore it since it's the same for all classes.

The core idea for making the best decision is the Bayes decision rule: To minimize the probability of error, we should choose the class with the highest posterior probability.

Decide $\omega_1$ if $P(\omega_1|x) > P(\omega_2|x)$; otherwise, decide $\omega_2$.

Since the evidence $p(x)$ is just a scale factor, we can use an equivalent rule that is often easier to compute:

Decide $\omega_1$ if $p(x|\omega_1)P(\omega_1) > p(x|\omega_2)P(\omega_2)$; otherwise, decide $\omega_2$.

2.2 General Bayesian Decision Theory

The simple fish example can be generalized to more complex scenarios. We can have:

  1. Multiple features, represented by a feature vector $\mathbf{x}$.
  2. More than two categories, $c > 2$.
  3. Different costs for different types of errors. Misclassifying a salmon as a sea bass might be more costly than the reverse.

To handle different costs, we introduce a loss function, $\lambda(\alpha_i|\omega_j)$, which defines the cost incurred for taking action $\alpha_i$ (e.g., deciding class $i$) when the true state of nature is $\omega_j$.

With a loss function, our goal is no longer just minimizing errors but minimizing the total cost, or risk. The conditional risk of taking action $\alpha_i$ given an observation $\mathbf{x}$ is the expected loss:

$$ R(\alpha_i | \mathbf{x}) = \sum_{j=1}^{c} \lambda(\alpha_i | \omega_j) P(\omega_j | \mathbf{x}) $$

The general Bayes decision rule is now: choose the action $\alpha_i$ that minimizes the conditional risk $R(\alpha_i | \mathbf{x})$. The minimum possible overall risk you can achieve with this rule is called the Bayes risk. It's the best performance theoretically possible for the problem. 🏆

2.3 Discriminant Functions and Decision Surfaces

A classifier's job is to take a feature vector $\mathbf{x}$ and assign it to one of $c$ classes. A useful way to represent this is with a set of discriminant functions, $g_i(\mathbf{x})$, one for each class. The classifier assigns $\mathbf{x}$ to class $\omega_i$ if its discriminant function gives the highest score:

Assign $\mathbf{x}$ to $\omega_i$ if $g_i(\mathbf{x}) > g_j(\mathbf{x})$ for all $j \neq i$.

For a Bayes classifier that aims to minimize error, a natural choice for the discriminant function is the posterior probability itself, $g_i(\mathbf{x}) = P(\omega_i|\mathbf{x})$. However, since the decision rule only cares about which function is largest, we can use any monotonically increasing function of the posterior. This trick can simplify the math a lot. A very common choice is:

$$ g_i(\mathbf{x}) = \ln p(\mathbf{x}|\omega_i) + \ln P(\omega_i) $$

Using the natural logarithm ($\ln$) turns products into sums and makes working with exponential functions (like the Gaussian density) much easier.

The decision rule effectively divides the feature space into decision regions, $\mathcal{R}_1, \mathcal{R}_2, \ldots, \mathcal{R}_c$. The borders between these regions are called decision boundaries or decision surfaces. These are the points in the feature space where a tie occurs, i.e., $g_i(\mathbf{x}) = g_j(\mathbf{x})$ for some $i \neq j$.

2.4 The Normal (Gaussian) Density

While Bayesian theory is general, its structure is determined by the class-conditional densities $p(\mathbf{x}|\omega_i)$. The most widely used density is the multivariate normal (or Gaussian) density. This is because it's mathematically easy to work with and often provides a good model for real-world data, where features are corrupted by many small, independent noise sources.

The multivariate normal density in $d$ dimensions is defined by a mean vector $\mu$ (the center of the data cloud) and a $d \times d$ covariance matrix $\Sigma$ (which describes the shape and orientation of the cloud). The formula is:

$$ p(\mathbf{x}) = \frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}} \exp\left[-\frac{1}{2}(\mathbf{x}-\mu)^T\Sigma^{-1}(\mathbf{x}-\mu)\right] $$

Points of constant density form hyperellipsoids in the feature space. The term $(\mathbf{x}-\mu)^T\Sigma^{-1}(\mathbf{x}-\mu)$ is the squared Mahalanobis distance from $\mathbf{x}$ to the mean $\mu$, which accounts for the covariance of the data.

2.5 Discriminant Functions for the Normal Density

When we assume that our class-conditional densities $p(\mathbf{x}|\omega_i)$ are multivariate normal, with mean $\mu_i$ and covariance $\Sigma_i$, our log-discriminant function becomes quadratic. The shape of the resulting decision boundaries depends on the covariance matrices.

Case 1: $\Sigma_i = \sigma^2\mathbf{I}$

This is the simplest case. All classes have identical, spherical covariance matrices. This means the data in each class forms a spherical cloud of the same size. The discriminant functions become linear, and the decision boundaries are hyperplanes. If the priors $P(\omega_i)$ are equal, the classifier simply assigns a point to the class with the nearest mean vector. This is called a minimum-distance classifier.

Case 2: $\Sigma_i = \Sigma$

Here, all classes share the same covariance matrix, but it can be an arbitrary one. The data clouds are hyperellipsoids of the same size and orientation. The discriminant functions are still linear, and the decision boundaries are hyperplanes. However, they are generally not perpendicular to the line connecting the class means. The distance metric used here is the Mahalanobis distance.

Case 3: $\Sigma_i$ is arbitrary

This is the most general case, where each class has its own mean and covariance matrix. The discriminant functions are now quadratic. The decision boundaries are hyperquadrics, which can be hyperplanes, hyperspheres, hyperellipsoids, or more complex shapes like parabolas and hyperbolas. This allows for much more complex decision regions.
